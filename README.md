# 🐦 Flappy Bird — Pygame

A simple **Flappy Bird-style game built with Python and Pygame**.
The player controls a bird and must navigate through obstacles without colliding with them.

## 🎮 Features

* 🐦 Flappy Bird-style gameplay
* 🎯 Score tracking
* 🚧 Moving pipes/obstacles
* 💥 Collision detection
* 🕹️ Keyboard controls
* 🔄 Restartable gameplay
* 🎨 Pygame-based graphics

## 🛠️ Technologies Used

* **Python 3**
* **Pygame**

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/alone-ai7/flappy-bird-pygame.git
cd flappy-bird-pygame
```

### 2. Install Pygame

```bash
pip install pygame
```

If your system uses `pip3`:

```bash
pip3 install pygame
```

### 3. Run the game

Open the `flappy bird` folder and run the main Python file:

```bash
python main.py
```

> If the main file has a different name, replace `main.py` with the appropriate filename.

## 🕹️ How to Play

* Press **Space** to make the bird fly upward.
* Avoid hitting the pipes.
* Pass through the gaps to increase your score.
* The game ends when the bird collides with an obstacle or the ground.

## 🎯 Objective

The objective is to achieve the highest score possible by successfully navigating the bird through as many pipe gaps as possible.
